# Personal Portfolio Website

## Overview

This project is a personal portfolio website designed to present my skills, projects, and basic information in a simple and organized way. It acts as an online profile where visitors can quickly learn about my work and technical abilities.

## Features

* About Me section introducing the developer
* Skills section highlighting technical abilities
* Projects section displaying completed work
* Contact section for communication
* Clean and simple web layout

## Technologies Used

HTML
CSS

## Project Structure

index.html – main webpage of the portfolio
style.css – styling and design of the website
README.md – documentation of the project

## How to Run

1. Download or clone this repository
2. Open **index.html** in any web browser
3. The portfolio website will load and display the content
